# Fit test coin

A 25 mm coin, 2.6 mm thick, with the same holes as the bracket legs: Ø8.6 center
(for the 8.25 mm bushing) and 4 × Ø3 screw holes, 14 mm apart. Print it first to
check the fit before printing a whole part.

Rebuild: `python3 build_stl.py && python3 ../make_3mf.py fit_test_coin.stl ../servo_bracket/Servo-U-Bracket.3mf`
